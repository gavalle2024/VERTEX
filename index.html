Base de datos requerida

Seleccione la carpeta que contiene vertex.db.

Puede elegir db/ del proyecto o cualquier carpeta autorizada. Se usará vertex.db; si no existe, se pedirá confirmar su creación. El navegador recuerda el acceso, pero no expone la ruta absoluta.

Actualizar base de datos

Se conservarán todos los proyectos. Antes de actualizar se creará y verificará un respaldo exacto del archivo original. Si no se puede respaldar, no se aplicará la migración.

No cierre la ventana ni abra la base con otra aplicación durante la actualización. Para volver a la versión anterior, use una copia del respaldo con esa versión de VERTEX.
